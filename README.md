# pongDuinoProject
Pong like game using SSD1306 Oled display, arduino uno and analog joystick


My original goals for this project was just to create a cool pong like game because i liked playing pong as a kid with friends and family. The parts I originally was planning on using consisted of the button, Led 8X8 Display and shift register. The parts I ended up using though was the SSD1306 oled display and the analog joystick, as using these parts made my project not only easier but it also made it much more retro like I wanted it to like rather then if i had used the 8x8 display.
My approach for the project was first to plug everything into place and get everything to turn on. I found working on one thing at a time when you are working on a big project helps in focusing on it and getting it done in a timely manner. Then i wanted to focus on Drawing the paddles, ball and middle line to get the game on the board, then finally i focused on the functionality of the game. Using the oled display made my experience much more tolerable then if I had used the 8x8 display and much easier as well. The hardest part of making my pong replica game was most definitely the collision checking, as it still is sort of finnicky at times.
